# Estudos de JavaScript

Repositório criado para documentar minha evolução nos estudos de JavaScript, com exercícios práticos desenvolvidos durante meu processo de aprendizado em desenvolvimento Front-end.

## Sobre o projeto

Este projeto reúne exercícios de lógica de programação, manipulação do DOM e interatividade com HTML e JavaScript.

## Conteúdos praticados

- Variáveis e tipos primitivos
- Operadores
- Estruturas condicionais
- Funções
- Arrays e objetos
- Estruturas de repetição
- Manipulação do DOM
- Eventos
- Validação de formulários
- Captura de dados de inputs

## Tecnologias utilizadas

- HTML5
- JavaScript

## Estrutura do projeto

    estudos-javascript/
    └── estudos-javascript/
        ├── index.html
        └── script.js

## Objetivo

Praticar os fundamentos de JavaScript, desenvolver minha lógica de programação e construir uma base sólida para atuar profissionalmente como desenvolvedor Front-end.

Este repositório será atualizado conforme meu avanço nos estudos.
